# react-webpack-course-landing-page

This project is ~~fake~~ course landing page.

---

# Functions

- This page has navbar, footer and sections: Hero, About, Program, How it works, Reviews, FAQ, Register;
- This page has form registration and modal;
- This page can send letter to inputted email address;
- This page uses emoji (font Noto Color Emoji) and svg icon;
- This page uses lazy loading

# Used stack technology

- Webpack;
- ReactJS;
- CSS3, SCSS;
- HTML;
- Typescript;
- Libraries: @emailjs/browser;
- Webpack plugins: terser-webpack-plugin, mini-css-extract-plugin, html-webpack-plugin, define-plugin, dotenv-webpack;
- Loaders: style-loader, css-loader, MiniCssExtractPlugin.loader, @svgr/webpack, asset/resource module, babel-loader

# Webpack config

This config is used for development and production mode. But this config is in folder config and webpack.config.ts.
